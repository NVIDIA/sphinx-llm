Maintainers
===========

If you're contributing to sphinx-llm, start with the development setup below.
You can build the site locally, run the relevant checks and prepare a pull
request without setting up a summary provider.

When you're changing documentation, read the writing guide before drafting.
It explains how we introduce examples and keep the reference material
consistent with the code. Release instructions are here too, for maintainers
with repository write access.
